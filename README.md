### Текст задачи
@Invoke.
Разработайте аннотацию @Invoke, со следующими характеристиками:
Целью может быть только МЕТОД
Доступна во время исполнения программы
Не имеет свойств
Создайте класс, содержащий несколько методов, и проаннотируйте хотя бы один из них аннотацией @Invoke. 
Реализуйте обработчик (через Reflection API), который находит методы, отмеченные аннотацией @Invoke, и вызывает их автоматически.
### Алгоритм решения
Создаём аннотацию, которая помечает методы для автоматического вызова.
Определяем, что эта аннотация может применяться только к методам и будет доступна во время выполнения программы.
Аннотация не имеет параметров — это просто маркер.
Когда обработчик видит эту аннотацию на методе, он понимает, что этот метод нужно вызвать автоматически

СОЗДАНИЕ ПРИМЕРА ДЛЯ @Invoke
Создаём класс с несколькими методами.
Помечаем некоторые методы аннотацией @Invoke.
Добавляем в методы логику, которая изменяет состояние объекта (например, устанавливает флаги или добавляет текст в строку).
Добавляем методы для проверки состояния объекта и метод для сброса состояния.
Этот класс будет использоваться для тестирования автоматического вызова методов.

####СОЗДАНИЕ ОБРАБОТЧИКА ДЛЯ @Invoke
Создаём метод, который принимает любой объект.
Метод получает все методы объекта через Reflection API.
Метод проходит по всем методам и проверяет каждый: если метод помечен аннотацией @Invoke, он вызывает этот метод.
Используем специальный инструмент — Reflection, который позволяет находить и вызывать методы по их названиям и аннотациям.
